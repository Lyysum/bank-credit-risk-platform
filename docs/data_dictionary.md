# 数据字典与分层说明

## 数据来源

项目生成固定随机种子的合成个人信贷申请样本，不含真实客户信息。生成器模拟 18 个月申请、申请渠道、地区、负债收入比、信用历史、逾期次数、申请用途和标签；并注入少量空值、重复主键和负金额，用于演示质量治理。

## 数仓分层

| 表 | 层 | 粒度 | 说明 |
|---|---|---|---|
| `ods_applications` | ODS | 一行一条原始申请事件 | 保留生成的质量问题 |
| `dwd_applications` | DWD | 一行一笔有效申请 | 去重、过滤字段越界，派生收入/DTI 分箱和贷款收入比 |
| `dwd_rejected_applications` | DWD 隔离 | 一行一笔被隔离申请 | 保留异常记录用于审计 |
| `dws_monthly_risk` | DWS | 月 | 申请量、违约数、违约率、平均贷款额 |
| `dws_channel_risk` | DWS | 渠道 | 渠道风险汇总 |
| `dws_region_risk` | DWS | 地区 | 地区风险汇总 |
| `ads_*_kpi` | ADS | 客群或月份 | 面向分析与展示的指标表 |
| `ads_risk_scores` | ADS | 一笔申请 | 模型分数、风险分层和业务分析字段 |
| `ads_model_feature_importance` | ADS | 一项模型特征 | 线性模型系数绝对值或树模型内置重要性 |

## 核心字段

| 字段 | 含义 |
|---|---|
| `application_id` | 合成申请编号 |
| `application_month` | 申请月份，按时间切分训练、验证和测试集 |
| `annual_income` / `loan_amount` | 年收入 / 申请贷款金额，单位为人民币元 |
| `debt_to_income` | 负债收入比，范围 0–1 |
| `delinquencies_2y` | 近两年模拟逾期次数 |
| `default` | 合成违约标签，1 表示违约，0 表示未违约 |
| `risk_score` | 模型估算的合成数据违约概率 |
| `risk_band` | 展示用固定分箱：低 <0.25，中 0.25–0.5，高 ≥0.5 |

模型决策阈值在验证集上按 F1 搜索，与展示用风险分层是两个不同概念。
