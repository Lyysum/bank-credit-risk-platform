# 项目讲解提纲

## 一分钟介绍

我做了一个本地可复现的银行个人信贷风险分析原型，使用合成数据避免个人信息风险。流水线先把原始申请写入 SQLite ODS，再在 DWD 去重、隔离金额和字段越界记录并派生特征，汇总成 DWS/ADS 指标；随后按月份做训练、验证、测试时间切分，比较逻辑回归和随机森林，根据验证集表现选择模型，在验证集选阈值，最后把申请评分和业务指标展示在 Streamlit 看板。

## 可以展开的工程问题

1. **为什么按时间切分？** 随机切分容易把未来分布泄漏到训练数据。按月份切分更接近模型上线后预测未来的场景。
2. **为什么保留拒绝记录？** 把异常数据写入隔离表，能量化剔除原因并留审计路径，不是静默删除。
3. **为什么比较 PR-AUC 和 ROC-AUC？** 违约属于相对少数类别；ROC-AUC看整体排序，PR-AUC更直接观察正类检出表现。项目同时报告精确率、召回率、F1、Brier 分数和混淆矩阵。
4. **如何选阈值？** 在验证月份上搜索 F1 较优阈值，最终只在更晚的测试月份报告一次指标。业务上线时需按漏判/误报成本和运营容量制定策略。
5. **有哪些限制？** 标签机制和客群分布是合成的；没有真实标签时序、拒绝样本、经济周期变化或监管审查。指标不能外推到任何银行的真实业务。

## 简历写法（仅写自己能复述的内容）

基于 Python、Pandas、SQLite、Scikit-learn 与 Streamlit 实现个人信贷风险分析原型；构建 ODS/DWD/DWS/ADS 本地数仓，处理重复键与异常值并输出质量指标；对逻辑回归、随机森林进行按月时间外验证，输出风险评分、模型指标和交互式客群看板。训练数据为可复现合成数据，项目指标仅作方法演示。
